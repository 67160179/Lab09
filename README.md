## ส่วนที่ 7: Enhancement

### คำถาม 7.1

รีเซ็ต timer

**คำตอบ:**

```js
// รีเซ็ตเวลา task กลับไปค่าเริ่มต้น (30 นาที)
function resetTimer(id) {
  // หา task จาก id
  const task = tasks.find((t) => t.id === id);
  if (!task) return; // ถ้าไม่เจอให้หยุด

  // หยุด timer ที่กำลังทำงานอยู่
  clearInterval(task.intervalId);

  // ตั้งเวลาใหม่เป็นค่าเริ่มต้น (duration)
  task.timeLeft = task.duration;

  // เปลี่ยนสถานะเป็นหยุด
  task.isRunning = false;

  // อัปเดตหน้าจอใหม่
  renderTasks();
}
```

### 7.2 วิธีใดในการเก็บ tasks ไว้ใน LocalStorage เพื่อไม่ให้หายเมื่อรีเฟรชหน้า

```js
// บันทึกข้อมูล tasks ลงใน LocalStorage ของ browser
// JSON.stringify แปลง array/object → string เพราะ LocalStorage เก็บได้แค่ string
localStorage.setItem("tasks", JSON.stringify(tasks));

// โหลดข้อมูล tasks จาก LocalStorage กลับมาใช้
// JSON.parse แปลง string > array/object กลับมาเป็นข้อมูลเดิม
// ถ้าไม่มีข้อมูล (ครั้งแรกที่เปิดเว็บ) ให้ใช้ array ว่างแทน
tasks = JSON.parse(localStorage.getItem("tasks")) || [];
```

### 7.3 ถ้าต้องการให้ผู้ใช้กำหนดเวลา timer เอง จะต้องแก้ไขฟังก์ชันไหนบ้าง

แก้:

- เพิ่มช่องกรอกเวลา
- addTask()
- การแสดงผลเวลา

### 8.1 ทำไม renderTasks() จึงต้องเรียกหลายครั้ง มีวิธี DRY ที่ดีกว่าหรือไม่

เพราะ UI ไม่เชื่อมกับ state โดยตรง จึงต้องวาดใหม่ทุกการเปลี่ยนค่า วิธีที่ดีกว่าคืออัปเดตเฉพาะจุด

### 8.2 ถ้าเปลี่ยนจาก setInterval เป็น requestAnimationFrame จะส่งผลดีหรือไม่

ไม่เหมาะ เพราะใช้กับ animation 60fps แต่ timer ต้องการความแม่นระดับวินาที

### 8.3 ในโค้ดที่ใช้ setInterval() มี Memory Leak ที่อาจเกิดขึ้นได้หรือไม่

อาจเกิดหากลบ task โดยไม่หยุด interval ก่อน
